---
description: "Create concise weekly status reports in Markdown"
---

Create a weekly status report in Markdown format.

- Use exactly these sections in this order: Accomplishments, Blockers, Next Week.
- Write each section as a Markdown heading followed by bullet points only.
- Keep the total output to a maximum of 20 lines.
- Use a professional tone and concise, factual wording.
- Do not use fluff words, filler language, or marketing-style phrasing.
- Keep bullets short, specific, and relevant to the reporting period.
- Include completed work under Accomplishments.
- Include unresolved issues, risks, or dependencies under Blockers.
- Include planned work for the upcoming period under Next Week.
- Do not use tables, paragraphs, or numbered lists.
- Use plain Markdown bullets with no extra commentary.
